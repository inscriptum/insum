# schema/

Bundled fallback schema artifact (`inscriptum-schema.json`) for
`insum schema` and `insum validate` — the reserve source when neither an
explicit `--schema` file nor the plugin's runtime artifact is available.

Provenance: the file is a byte-for-byte snapshot of the runtime artifact
generated by the Inscriptum plugin (`schema.json` in the plugin's own
directory), plugin 0.14.1 as of 2026-11-08. It is never edited by hand:
when the plugin schema changes, refresh the snapshot by copying the freshly
generated runtime artifact. `plugin_version` is excluded from
`schema_hash`, so ordinary plugin releases do not force a refresh — only
real schema changes do.

The fallback is labeled `bundled-fallback` in every response; it never
lifts the validation level above `structural` and is never evidence that
writing is allowed.
